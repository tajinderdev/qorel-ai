# ADAPTIVE ASSESSMENT ENGINE

## 1. Diagnostic Assessment Lifecycle
1. **Diagnostic Generation**:
   - 3-4 targeted questions covering foundational to expert concepts.
   - Mix of Code Prediction / Bug Spotting, Architectural Tradeoff, and Open Conceptual Explanation.
2. **Real-Time Evaluation**:
   - Multiple Choice: Evaluated instantly with deterministic feedback.
   - Code Bug / Output: Evaluated with test case analysis.
   - Freeform Explanation: AI provider / Mock provider inspects semantic coverage of required keywords, mental models, and edge cases.
3. **Mastery Adjustment**:
   - Initial concept mastery generated based on question weights.

## 2. In-Lesson Checkpoints
- Integrated directly after each conceptual/visual explanation.
- If failed: Immediate remedial breakdown offered ("Explain Differently") without penalty to encourage deep understanding.
