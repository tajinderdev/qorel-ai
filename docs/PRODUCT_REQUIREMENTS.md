# PRODUCT REQUIREMENTS DOCUMENT (PRD)

## 1. Executive Summary
**Qorel AI** is an AI Interactive Learning Tutor platform built specifically for software engineers and technical professionals. Unlike static course generators or video platforms, Qorel AI operates as an intelligent, conversational, and visual personal tutor that diagnoses existing knowledge, personalizes dynamic learning paths, explains complex concepts with synchronized voice and procedural 3D/2D interactive visualizations, and actively tests understanding through code debugging and open-ended conceptual explanations.

## 2. Core Value Proposition
- **Adaptive Diagnostic**: Never teach what the learner already knows. Dynamically detects proficiency and skips redundant material.
- **Multi-Modal Active Learning**: Blends technical depth, procedural 3D architecture/data-flow visualizers, synchronized speech narration, and live interaction.
- **Explainable Mastery Tracking**: Replaces opaque percentage bars with granular, evidence-backed concept mastery scores (strengths, weaknesses, diagnostic results, and checkpoint proofs).
- **Course Warehouse with Memory**: Reuses canonical topic graphs while personalizing the path for each learner; remembers past mastery across sessions.
- **Target Role Roadmaps**: Maps learned skills against engineering role goals (e.g., Senior Full-Stack Engineer, AI Engineer, Distributed Systems Architect) with transparent skill gap roadmaps.

## 3. Target Audience & Persona
- **Primary Persona**: Mid-level to Senior Software Engineers, DevOps/Cloud Engineers, and AI Practitioners who need to rapidly understand complex technical systems, algorithms, architectures, or frameworks without sitting through hours of introductory lectures.
- **Key Pain Point**: Traditional courses waste 80% of the engineer's time on basics they already know, while LLM chat windows lack structured state, interactive visual simulation, and verifiable knowledge progression.

## 4. Key Metrics & Success Criteria
- Time-to-comprehension reduced by >60% compared to standard documentation/video courses.
- Diagnostic accuracy >90% in detecting learner's prerequisite mastery.
- 100% end-to-end reliability across the interactive learning loop with seamless fallback when external AI/Voice keys are not configured.
